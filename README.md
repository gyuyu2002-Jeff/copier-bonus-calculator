# 第四季影印機責任激勵獎金計算器 (台數獎金計算)

單頁線上影印機責任額與激勵獎金計算工具（適用 2026 年 10-12 月第四季）。

## 功能特色
- 支援協力單位（3台門檻）與一般單位（4台門檻）之責任額與懲罰扣除計算
- 內建協力單位清單（屏東、板橋、宜蘭、苗栗、南投、嘉義、北台中、南台南、新莊、基隆、專一、中正、員林、彰化、南高雄、內湖）
- 自動扣除大案超出台數上限（本牌單一客戶限 3 台、新開發單一客戶限 6 台）
- 依第四季最新級距試算 A 方案（新舊成對組數加計）與 B 方案（總台數達標獎勵）
- 新開發未滿 3 台獎勵減半機制防呆
- 即時計算責任額缺口與淨結算金額
